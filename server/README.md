# 📡 Vedanco Enterprise Backend Server — Supabase Edition

A high-performance, robust, and secure backend system crafted with **Node.js, Express, Supabase (PostgreSQL)**, and featuring a dual-automated notification system powered by **Nodemailer**.

---

## ⚡ Features

1. **Lead & Inquiry Storage:** Stores all client inquiries from the "Get A Free Quote" and "Hire Now" forms with dynamic statuses (`New`, `In-Progress`, etc.) in your hosted Supabase Postgres database.
2. **Newsletter Subscriptions:** Keeps track of subscribers with validation checking to prevent duplicate subscriptions.
3. **Automated Twin-Email Dispatch System (Nodemailer):**
   - **Admin Notification:** Instantly emails the agency team (`info@vedanco.com`) with a detailed breakdown of the client's inquiry, phone, service, and message.
   - **Client Confirmation:** Sends a gorgeous, branded HTML thank-you email to the client confirming receipt and outlining the next steps (discovery call, NDA, etc.).
4. **Dynamic CORS Setup:** Configured to allow flawless asynchronous operations between your local development environments (ports `3000` / `5173`).
5. **Robust Global Exception Filter:** Includes centralized request logging via `morgan` and complete error-handling middleware to ensure absolute server uptime.

## 🛢️ Supabase SQL Database Schema

Before running the server, log into your [Supabase Dashboard](https://supabase.com), go to your project's **SQL Editor**, and copy-paste the following queries to create the required tables in one click:

```sql
-- Create contacts table
CREATE TABLE IF NOT EXISTS contacts (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name TEXT NOT NULL,
  email TEXT NOT NULL,
  phone TEXT DEFAULT '',
  message TEXT NOT NULL,
  service TEXT DEFAULT 'General Inquiry',
  status TEXT DEFAULT 'New',
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- Create newsletter subscribers table
CREATE TABLE IF NOT EXISTS subscribers (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  email TEXT NOT NULL UNIQUE,
  active BOOLEAN DEFAULT TRUE,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);
```

## 🚀 Getting Started

Follow these simple steps to run the backend server locally:

### 1. Install Server Dependencies
Open a separate terminal window, navigate into the server directory, and install:
```bash
cd server
npm install
```

### 2. Configure Environment Variables (`.env`)
Open the `server/.env` file and customize your setup with your Supabase keys (Found in Project Settings -> API):
```env
PORT=5000
SUPABASE_URL=https://your-project-id.supabase.co
SUPABASE_KEY=your-supabase-anon-key

# Gmail App Password for SMTP Notification
EMAIL_USER=your_email@gmail.com
EMAIL_PASS=your_gmail_app_password
EMAIL_RECEIVER=info@vedanco.com
```

### 3. Start the Server
Run the dev script:
```bash
npm run dev
```
You should see:
```text
📡 Supabase Client initialized successfully.
🚀 Server up and running in development mode on port 5000
```

## 📡 REST API Documentation

| Endpoint | Method | Access | Body Parameters | Description |
| :--- | :--- | :--- | :--- | :--- |
| `/health` | `GET` | Public | *None* | Verifies if server is active and healthy. |
| `/api/contacts` | `POST` | Public | `name`, `email`, `phone`, `message`, `service` | Submits a project lead form, saves to Supabase, and sends dual emails. |
| `/api/subscribe` | `POST` | Public | `email` | Saves email to Supabase subscribers list. |
| `/api/contacts` | `GET` | Private/Admin | *None* | Lists all inquiries from Supabase sorted by newest first. |
